# Figures

This directory is for publication-quality figures generated by the analysis scripts.

Examples from the pilot include:

- jamming timeline
- AGC comparison
- receiver-noise comparison
- spectrum comparison
- satellite-count comparison
- C/N0 comparison
- Logistic Regression confusion matrix
- Random Forest confusion matrix
- Random Forest feature-importance plot
- grouped-validation confusion matrices

Raw screenshots of terminal execution are kept separately as implementation evidence and are not intended to replace thesis-quality figures.
